# Virus Vanquisher

Virus Vanquisher is a multi-level game built collaboratively in Godot using GDScript.

The game includes player movement, projectile mechanics, collectibles, multiple enemy types, boss-style characters, custom assets, and three playable levels.

## Features

- Player movement and combat
- Projectile mechanics
- Collectible items
- Multiple levels and scenes
- Multiple enemy types
- Boss-style characters
- Custom visual assets
- Intro/start scene

## Codebase

Key scripts include:

- `Player.gd`
- `Projectile.gd`
- `Collectible.gd`
- `MiniVirus.gd`
- `RansomwareRex.gd`
- `TrojanTitan.gd`
- `WormKing.gd`
- `WormMinion.gd`
- `Level1.gd`
- `Level2.gd`
- `Level3.gd`

## Tech Stack

- Godot Engine
- GDScript

## My Contribution

This was a collaborative TSA project developed by a three-person team. I worked across the Godot project during development and helped integrate gameplay components, scenes, levels, and scripts into a functioning game.

Because development was collaborative, individual systems were not strictly divided between team members.
